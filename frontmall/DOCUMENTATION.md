# Frontmall Theme - Installation (v0.1.1)

## Install
1. Appearance > Themes > Add New > Upload Theme > frontmall.zip > Activate.
2. On activation the theme auto-creates policy/support pages (About, Contact,
   Privacy, Terms, Shipping, Returns, Warranty, Payment Methods, Cookie, FAQ,
   Track Order).
3. Appearance > Frontmall Setup: install WooCommerce plus the recommended stack.
4. WooCommerce > Products > Import: upload your cleaned product CSV.
5. WooCommerce > Merchant Compliance: clear criticals, then request review.
